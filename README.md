![My Tasks Preview](./src/media/Essentials-hub-home.png)

## Description

*Essentials Hub* is a modern and fully functional e-commerce web application built with React, designed to deliver a smooth and responsive online shopping experience. The store features a curated selection of clothing, electronics, and jewelry products with dynamic browsing, interactive UI elements, and seamless cart management.

This project was developed to demonstrate modern React front-end development concepts through the creation of a fully functional online store. The application focuses on dynamic state management for cart functionality, reusable component architecture, responsive design principles, client-side routing, local storage persistence, and interactive user experiences enhanced with smooth animations and transitions. The project also emphasizes clean UI structure, efficient rendering of product data, and seamless navigation between the home page, catalog, and shopping cart sections.

## Features

- Responsive and modern user interface
- Functional shopping cart with quantity management
- Smooth animations and interactive transitions
- Product catalog with category browsing
- Dedicated home page with featured sections
- Persistent cart data using local storage
- Reusable and scalable React component structure
- Dynamic rendering of products and cart items
- Client-side routing for seamless navigation

## Key Implementation Details ⁠

- Built using React functional components and a reusable component-based architecture
- Implemented global state management using Zustand for cart functionality and shared application state
- Developed a fully functional shopping cart with dynamic quantity adjustments and real-time total calculations
- Used React hooks such as useState, useEffect, and useRef for UI state handling, side effects, and DOM interactions
- Integrated React Router for seamless client-side navigation between pages
- Designed responsive layouts using CSS Grid, Flexbox, and media queries
- Persisted cart data using Local Storage to maintain user selections across sessions
- Dynamically rendered products and categories through reusable React components
- Not Found Page for when there is a wrong route
